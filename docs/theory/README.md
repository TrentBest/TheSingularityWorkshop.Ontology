# Ontology Theory — Learning Path

This modular path teaches the semantic domain owned by Ontology. Read in order for a first pass, or open any chapter independently.

## Chapters

1. [01 — Meaning Before Manifestation](01-MEANING-BEFORE-MANIFESTATION.md) — why semantic identity should be separate from implementation.
2. [02 — Classification Without a Universal Taxonomy](02-CLASSIFICATION-AND-RANK.md) — the canonical Workshop profile, arbitrary-rank ontologies, and the difference between rank and relationships.
3. [03 — Coordinates, Addresses, and Address Spaces](03-COORDINATES-AND-ADDRESS-SPACES.md) — identity, versioning, scalar and N-dimensional coordinates, bounded spaces, and dense offsets.
4. [04 — Relationships, Coexistence, and Materialization](04-RELATIONSHIPS-AND-MATERIALIZATION.md) — cross-ontology relationships and the boundary between semantic possibility and stored actuality.

## Learning method

Each chapter begins with a recognizable problem, defines vocabulary, reasons about the model, shows a worked example, maps claims to source and tests, records limits, and offers exercises. Code links point to the current development branch; treat them as revision-specific evidence, not permanent line-level citations.

## Evidence labels

- **Implemented:** present in public source and exercised by tests.
- **Source-checked:** present in source but not independently executed as part of the cited example.
- **Conceptual:** illustrative, not runtime proof.
- **Open question:** a capability or guarantee requiring separate design and evidence.

This path does not duplicate finite-state-machine, workflow execution, MicroBundle lifecycle, repository, grammar, or protocol theory. Those subjects belong to their respective Workshop repositories.
